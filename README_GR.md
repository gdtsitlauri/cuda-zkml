# CUDA-zkML / PCANI: σύντομα στα ελληνικά

**Μπορεί μια υπηρεσία να αποδείξει ποιο νευρωνικό δίκτυο έβγαλε την απάντησή της, φθηνά, χωρίς η απόδειξη να
ξαναχρησιμοποιείται, και χωρίς να φανερώσει το μοντέλο ή την είσοδο;**

Ο prover φτιάχνει αποδείξεις μηδενικής γνώσης (Groth16) σε κάρτα γραφικών (CUDA). Η απόδειξη είναι 256 bytes και
ελέγχεται σε χιλιοστά του δευτερολέπτου, ακόμα και από smart contract.

Το **PCANI** χρησιμοποιεί μοντέλα από φθηνό έως ακριβό:
- αν το φθηνό μοντέλο είναι σίγουρο, αποδεικνύεται μόνο αυτό·
- αλλιώς πάμε στο επόμενο·
- η απόφαση δρομολόγησης είναι κι αυτή δεμένη με την απόδειξη.

## Τι βρήκαμε
1. **Η απόδειξη για κάθε δοκιμασμένο μοντέλο δεν αξίζει· μία απόδειξη για το επιλεγμένο αξίζει.**
   - Πρωτόκολλο v1: κόστιζε 54% περισσότερο από το να αποδειχθεί κατευθείαν το μεγάλο μοντέλο, άρα απορρίφθηκε.
   - Πρωτόκολλο v2: **14,94% λιγότερο κόστος**, με την ίδια ακρίβεια 96,11%. Μετρήθηκε σε GPU T4.
2. **Anti-replay:** κάθε απόδειξη δένεται με μια συνεδρία· απόδειξη από άλλη συνεδρία απορρίπτεται. Βρέθηκε και
   διορθώθηκε πραγματικό κενό ασφαλείας στο smart contract (input aliasing).
3. **Το κύκλωμα δεν είναι «χαλαρό»:** ανεξάρτητος έλεγχος βρίσκει 0 ελεύθερες τιμές, σε έως 62.779 μεταβλητές.
4. **Πραγματικό ReLU σε εκπαιδευμένο μοντέλο:** ακρίβεια 97,3% → 97,1% ως ακέραιο μοντέλο. Η C++ και η Python
   δίνουν ακριβώς τα ίδια νούμερα.
5. **Ιδιωτικό μοντέλο και ιδιωτική είσοδος** πίσω από σφραγίδες Poseidon, ίδιες με το πρότυπο circomlib. Η
   δρομολόγηση γίνεται μέσα στο κύκλωμα.
6. **Τελετή MPC:** τα κλειδιά μπορούν να φτιαχτούν από πολλούς· αρκεί ένας έντιμος. Κάθε αλλοίωση απορρίπτεται.

## Τι δεν πέτυχε (γράφεται τίμια)

- Δεν έχει γίνει έλεγχος από κρυπτογράφο.

## Πού είναι τι
- `SUMMARY_FOR_SUPERVISOR_GR.txt`: απλή περιγραφή όλης της έρευνας για τον επιβλέποντα.
- `FUTURE_WORK_ROADMAP.md`: τι έγινε και τι απομένει.
- `docs/THREAT_MODEL.md`: το μοντέλο απειλών.
- `docs/TECHNICAL_DETAILS.md`: η πλήρης τεχνική περιγραφή.
- `src/`: ο prover σε CUDA.
- `python/`: τα πρωτόκολλα και τα πειράματα.
- `contracts/`: τα smart contracts.
- `tests/`: οι έλεγχοι (`tests/host/`: χωρίς GPU).
- `notebooks/`: τα notebooks για το Colab.
- `results/`: τα αποτελέσματα της T4.
